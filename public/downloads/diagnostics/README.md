## 共同模型与单位

一维、均匀、线弹性小应变杆，长度 `L=1000 mm`、截面 `A=100 mm²`、弹性模量 `E=210000 MPa=N/mm²`。轴向正方向由左向右，拉应力为正，反力表示支座作用于杆的力。

```text
体积 V = A L = 100000 mm³
刚度 k = E A / L = 21000 N/mm
K = [[k,-k],[-k,k]] N/mm
```

N–mm–s 系中质量单位为 Mg，`1 Mg=1000 kg`。MPa 与 mm 可以相容，不能只凭这两个单位判断混用。下面的端拉工况不含自重、其他体力与惯性。

## 示例一：密度误填，但当前端拉位移不变

关联诊断：[单位与数量级](https://simulearn.cn/diagnostic/units/)。

| 项目 | 正确密度输入 | 错误密度输入 |
| --- | ---: | ---: |
| 密度 / (Mg/mm³) | 7.85e−9 | 7.85e−6 |
| 质量 / Mg | 0.000785 | 0.785 |
| 质量 / kg | 0.785 | 785 |
| 右端拉力 P / N | 10000 | 10000 |
| 端位移 PL/(EA) / mm | 0.476190476190476 | 0.476190476190476 |
| 左端反力 / N | −10000 | −10000 |

质量扩大 1000 倍，但这两次参考计算的 K 与 F 相同，端拉静力方程不含密度，所以位移相同。材料输入仍需纠正；不能为了展示修正效果而编造位移变化。如果加入自重或惯性，必须重新写相应载荷/动力方程。本例未计算模态频率，不输出频率变化。

## 示例二：自由两节点杆与不平衡外力

关联诊断：[刚体运动与缺少约束](https://simulearn.cn/diagnostic/rigid-body/)。

两端均自由，外力 `F=[0,10000] N`。`K×[1,1]ᵀ=[0,0]ᵀ` 表明整体平移不产生轴力；同时外力合计 10000 N，当前静力载荷不满足整体平衡，因此没有平衡解。

脚本真实执行带部分选主元的高斯消元，第二列出现零主元，抛出 `SingularSystemError`，没有伪造位移。脚本的零主元判断只服务于这个可精确消去的小矩阵，不是通用求解器的病态性标准。自由杆即使承受平衡载荷，仍会因整体平移得到非唯一位移；“无平衡解”与“解不唯一”应区分。

若真实支承为左端轴向定位，取 `u左=0`，分区后实际求解得到 `u右=10000/21000=10/21 mm`。用原始方程 `R=Ku−F` 得左反力 −10000 N，右节点残差为零。

这不是“所有 pivot 警告都是刚体运动”的证明。真实日志中的接触状态、材料、单元、网格与数值病态等因素仍需分别检查。若实物本来允许自由运动，也不能为了消掉警告随意添加固定支座。

## 示例三：允许热滑移与两端轴向固定

关联诊断：[边界条件与支承意图](https://simulearn.cn/diagnostic/boundary/)。

均匀温升 `ΔT=50 K`，线膨胀系数 `α=12e−6/K`，无机械外载、侧向自由。自由热应变 `ε热=αΔT=0.0006`，热等效节点载荷为 `f热=EAε热[-1,+1]=[-12600,+12600] N`。

脚本对两组约束求解同一个热杆模型，再按 `σ=E[(u右−u左)/L−ε热]` 求应力；反力用原始 `R=Ku−f热` 恢复。

| 支承条件 | 右端位移 / mm | 轴向应力 / MPa | 左、右反力 / N |
| --- | ---: | ---: | --- |
| 左端定位，右端轴向自由 | 0.6 | 0 | 0，0 |
| 两端轴向固定 | 0 | −126 | +12600，−12600 |

若真实意图是允许滑移，却把右端锁住，应该修正该边界；如果实物两端确实不能伸长，压应力就是这一理想模型的响应，不能把所有固定热杆都当成建模错误。

这里仅讨论轴向约束且侧向自由，不是三向全固定。没有分析屈曲、塑性、摩擦、温度梯度或夹持区三维局部应力，不能据此判断真实热杆安全。
