# 力学与有限元基础：Python 参考算例

本目录配合六篇基础教程使用。脚本仅依赖 Python 3.10+ 标准库，不需要 NumPy、ANSYS 或 CAE 工作台。

- `verify_basics.py`：可阅读、修改和重新运行的完整计算脚本。
- `reference-results.json`：本次真实执行得到的参考结果，含组装矩阵、位移、反力、能量及网格误差。

## 运行与执行记录

把文件下载到同一文件夹，在终端运行：

```sh
python verify_basics.py --format table
python verify_basics.py --format json
python verify_basics.py --output my-results.json --executor "我在本机的 Python 环境"
```

`--output` 会写入指定文件，并覆盖同名旧文件。未指定时只打印结果，不写文件。请不要使用 `python -O`，脚本会拒绝关闭断言的运行方式。

## 参数、单位与模型范围

共同轴杆参数：`E = 210000 N/mm²`、`A0 = 100 mm²`、`L = 1000 mm`、端部拉力 `P = 10000 N`。采用小应变、线弹性、正弹性模量；左端位移为零，右端沿杆轴正向受拉，杆例不包含自重、弯曲、剪切和动力响应。

单位换算单独核对：`7850 kg/m³ = 7.85e-9 Mg/mm³`，体积 `100000 mm³`、质量 `0.000785 Mg = 0.785 kg`。在 `mm–Mg–s–N` 一致单位中，`g = 9810 mm/s²`，重量为 `7.70085 N`。这个重量没有加入轴杆拉伸的载荷向量。

均匀杆解析值：应力 `100 MPa`，应变 `0.000476190476190476`，伸长 `0.476190476190476 mm`。`x=250 mm` 时形函数为 `[0.75, 0.25]`，位移为 `0.119047619047619 mm`。两节点等量平移产生零应变。

另有一根简支梁，仅做力与力矩平衡：跨度 `2000 mm`，在左支点右侧 `500 mm` 施加 `10000 N` 向下集中力。取向上为正，得到 `RxA=0`、`RyA=7500 N`、`RyB=2500 N`；分别核对 `ΣFx`、`ΣFy`、关于 A 和 B 的力矩。这不是梁单元有限元求解。

## 两单元杆的组装与验证

两个等长单元各长 `500 mm`，局部刚度系数 `EA/h = 42000 N/mm`。脚本按单元自由度逐项组装：

```text
K = 42000 * [[ 1, -1,  0],
             [-1,  2, -1],
             [ 0, -1,  1]] N/mm
F = [0, 0, 10000] N
u0 = 0 mm
```

约束前矩阵对称，三个独立特征向量对应特征值 `0`、`42000`、`126000 N/mm`；其中零特征值表示刚体平移。施加 `u0=0` 后实际提取自由自由度子矩阵，以带部分选主元的高斯消元求解，并通过完整系统恢复约束反力。

结果为 `u=[0, 0.238095238095238, 0.476190476190476] mm`，左端反力 `-10000 N`。分别核对自由自由度残差、整体平衡、各单元轴力、`0.5 uᵀKu`、各单元应变能之和与准静态外力功 `0.5 P u_tip`。应变能为 `2380.95238095238 N·mm`；`1 N·mm = 0.001 J`。

补充串联两段杆：`L1=400 mm,A1=100 mm²,L2=600 mm,A2=50 mm²`，保持相同 E、P。两段伸长分别为 `0.190476190476190 mm` 和 `0.571428571428571 mm`，总伸长 `0.761904761904762 mm`，等效刚度 `13125 N/mm`。

## 变截面杆的真实矩阵求解与网格收敛

定义 `A(x)=A0*(1+x/L)`，E 为常数，右端施加 P，左端固定，轴力沿杆为 P。积分解析解：

```text
u_tip_exact = P*L/(E*A0)*ln(2) = 0.330070085980926 mm
U_exact = 0.5*P*u_tip_exact = 1650.35042990463 N·mm
```

每个线性位移单元采用 `k_e = E*A0*(1+x_mid/L)/h`。由于单元内 A(x) 是线性函数，这等于刚度积分的精确值；位移近似本身仍受网格影响。脚本对每个 N 真正组装 `(N+1)×(N+1)` 矩阵、施加边界条件并求解，不以已知端位移公式替代有限元方程。
