## 1. 单轴应力与横向约束是两种条件

材料假设为各向同性、小应变、线弹性，`E=210000 MPa`、`ν=0.3`。应力取拉为正。本例只使用三维本构的正应力子块，没有涉及工程剪应变与张量剪应变的约定。

当 `σ=[100,0,0] MPa`，实际解三阶本构方程得到：

```text
εx =  0.000476190476190476
εy = εz = -0.000142857142857143
```

若改成 `σx=100 MPa`、`εy=εz=0`，需由横向约束提供应力：

```text
σy = σz = 42.8571428571429 MPa
εx = 0.000353741496598639
Ex,约束 = E*(1-ν)/((1+ν)*(1-2ν)) = 282692.307692308 MPa
```

这里的约束有效模量不是把材料 E 改成一个新数值。两种结果都由同一各向同性本构得到；脚本另用柔度矩阵反算核对。

## 2. 平面刚体支承的秩检查

刚体位移在 `(x,y)` 处为 `ux=tx-y*θ`、`uy=ty+x*θ`。未知量顺序为 `[tx,ty,θ]`，平移单位 mm、角度 rad。

| 支承 | 约束行矩阵 | 秩 | 未排除的运动 |
| --- | --- | ---: | --- |
| A(0,0) 铰、B(2000,0) 竖向滚动约束 | `[[1,0,0],[0,1,0],[0,1,2000]]` | 3 | 本平面刚体的三个自由度均被排除 |
| x=0、1000、2000 的三个竖向滚动约束 | `[[0,1,0],[0,1,1000],[0,1,2000]]` | 2 | 水平平移；三行中另有一行相关 |
| A 铰、B 水平方向约束 | `[[1,0,0],[0,1,0],[1,0,0]]` | 2 | 绕 A 的刚体转动 |

若 `θ=0.001 rad`、`tx=ty=0`，B 点位移为 `[0,2] mm`。不能只数支座名称或约束行数来证明约束独立。

原矩阵各列的系数带有坐标尺度，不能把这些混合量纲数字直接解释为条件数。脚本同时令 `q3=Lref*θ`、`Lref=2000 mm`，把第三列除以 Lref，再计算秩，分别仍为 3、2、2。这里验证线性独立性，不分析真实弹性构件的柔度、内力分配或支座强度。

## 3. 不等长、不等截面杆的实际组装

`L1=400 mm,A1=100 mm²,L2=600 mm,A2=50 mm²`，同一 E。局部刚度系数为 `k1=52500 N/mm`、`k2=17500 N/mm`。在中节点施加 `5000 N`，右端施加 `10000 N`，均沿轴向正方向：

```text
K = [[ 52500,-52500,     0],
     [-52500, 70000,-17500],
     [     0,-17500, 17500]] N/mm
F = [0,5000,10000] N
```

与旧参考算例不同，这里中间节点有外力；两段轴力并不相等。

| 结果 | u0=0 mm | u0=0.2 mm |
| --- | ---: | ---: |
| u1 / mm | 0.285714285714286 | 0.485714285714286 |
| u2 / mm | 0.857142857142857 | 1.057142857142857 |
| 自由方程右侧 / N | `[5000,10000]` | `[15500,10000]` |
| 左端反力 / N | -15000 | -15000 |
| 两段轴力 / N | `[15000,10000]` | `[15000,10000]` |
| 两段平均应力 / MPa | `[150,200]` | `[150,200]` |
| 应变能 / N·mm | 5000 | 5000 |

分区方程为 `Kff*uf=Ff-Kfc*uc`。脚本独立运行对称行列替换：先用原 K 的约束列修正右端，再清除对应行列，约束行写成 `s*u0=s*g`，取原对角刚度尺度 `s=52500 N/mm`，最后求解。非零边界例的替换后对角项仍是 52500，右端为 `[10500,15500,10000] N`。两种方法的节点位移一致。

替换后约束行表示位移条件，不再是原始力平衡方程，矩阵也不应再用于恢复物理反力或计算应变能。所有反力均回到原矩阵计算 `R=K*u-F`；只检查替换后系统的残差会漏掉真实约束反力。

## 4. 非零规定边界位移下的能量

终态恒等式为：

```text
U = 0.5*uᵀ*K*u = 0.5*(Fᵀ*u + Rcᵀ*uc)
```

当 `u0=0.2 mm`，只计算 `0.5*Fᵀ*u` 会得到 `6500 N·mm`，遗漏的边界项为 `0.5*(-15000)*0.2=-1500 N·mm`，两者之和才是 `5000 N·mm`。增加共同平移不会改变杆内相对位移与应变能。

若把右侧每一项分别解释为外力或支座的实际加载功，需限定所有节点外力与规定支座位移都从零按同一比例准静态增加。若先无载整体平移，再保持支座位置加载，各个作用的实际路径功应按相应路径积分；不能无条件把终态三角形项当作每一步真实做功。终态代数能量恒等式仍然成立。

## 5. 两种热约束不要混用

设 `α=12e-6 /K`、`ΔT=50 K`，自由热应变为 `0.0006`。

- 仅轴向总应变为零、横向无应力时：`σx=-E*α*ΔT=-126 MPa`，`σy=σz=0`。总横向应变为 `0.00078`，包含热膨胀与轴向压应力的泊松效应。
- 三个方向的总正应变都为零时：`σx=σy=σz=-E*α*ΔT/(1-2ν)=-315 MPa`。

两者采用同一 E、ν、α，只是约束不同。这是理想均匀、各向同性线热弹性参考；不包含温度梯度、材料温变参数、屈曲或真实三维夹持效应。
