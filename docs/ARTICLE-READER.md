# 继续阅读与长文阅读体验

更新日期：2026-10-24（Asia/Shanghai）。适用于成功加载的公开知识教程和已发布的围岩工程案例。

## 阅读操作

正文上方提供可折叠的本篇目录、活动章节、标准/大字/特大字号、正文位置及回到正文开头。目录只根据公开正文的二、三级标题生成，保留安全的既有章节锚点，重复标题生成不同的稳定锚点；代码块、AI拓展、辅导对话和学习检验不进入正文目录。

重新打开文章时先提示上次的位置，由用户选择继续或从头阅读。首页和最近浏览中有已存位置的文章提供“继续阅读”入口，通过 `#reader-resume` 明确恢复；已有章节深链接优先，不会被旧位置覆盖。恢复使用章节及章节内比例，以适应手机/桌面、字号和内容高度变化。正文指纹变化时提示内容更新，只定位仍有效章节的起点，原章节失效则回到正文开头。

“正文位置”表示页面滚动位置，不代表看完、学习完成、运行验证或已掌握。

## 保存与清理

阅读位置与字号使用独立的 `simulearn-reading-position-v1` 本地存储键，不改写收藏或学习进度格式；暂不跨设备同步。只保存公开文章链接、章节标识和短标题、两个位置比例、时间及正文指纹，不保存正文、AI回复、问题、附件或账户数据。最多保留50篇文章的位置。

初次排版和知识树自动滚动不保存位置；用户滚动、目录导航或明确继续阅读后，才节流保存。仅成功加载的公开正文可启用，不接入私人学习工作台、共享记录、搜索页面或报错列表。

沿用最近浏览的暂停设置。暂停或记录被移除后，已经打开的文章不会重新写入旧位置；下一次重新打开且恢复记录后才继续保存。移除一条浏览记录会清理该文章位置；确认清空最近浏览或重置阅读列表时会同时清理所有位置，收藏按原有操作规则处理。正常清理位置保留字号设置。

存储被禁用、空间不足或格式损坏时，不显示保存成功。自动保存不会覆盖损坏数据；用户可以在最近浏览中确认清空阅读位置，恢复可用格式。字号保存失败时仍可在当前页面临时调整。

现有 JSON / Markdown 导出仍导出收藏与最近浏览的公开入口列表；本轮没有加入阅读位置的导出或导入。
