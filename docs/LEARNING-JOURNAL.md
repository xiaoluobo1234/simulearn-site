# AI 工程学习与学习记录

方案版本：v1.0；整理日期：2026-10-23（Asia/Shanghai）。本次改动属于教程模块，沿用 Astro、Worker、现有登录和 BOOKS R2 绑定，不更改 CAE 服务。

## 页面与流程

- `/learning`：AI 工程学习总览、首个 CSV 项目、下一项建议任务、四周建议和关联教程。所有计划均标为拟开展，验证案例均为待运行。
- `/learning/records`：学习记录、资料卡和知识笔记。未登录也可以填写和导出；登录后才可保存到账户。无虚构示例经历。
- `/learning/shared?owner=<userId>&id=<itemId>`：已明确公开的正文。未公开、撤回或删除后不可读取。

每次学习结束先填写六项：学习日期、问题、实际尝试、结果或报错、未理解的问题、附件或来源。完整字段保留执行环境、预期与实际输出、复现状态、适用版本和条件、未测试范围、下一任务与完成条件。日期缺失保留未提供，方案日期不充当学习日期。

资料卡登记原始 URL、作者或机构、类型、适用版本、实际阅读范围、收藏用途、个人理解、支持结论、阅读状态、下一阅读部分与受限信息。知识笔记和资料卡按 ID 引用，不在每条记录内重复复制。

学习自评、审核状态、公开状态分别存储。保存不会自动升级学习能力；AI 整理不会自动核对、保存或公开。AI 建议在原始记录旁预览，用户选择后才写入编辑稿，仍需保存。缺少 Dify 配置或服务不可用时，保留输入并可复制完整提示词手动整理。

## 隐私与版本

新记录默认私人草稿。服务端从 `simulearn_sess` 的签名 JWT 查询真实账户，使用账户 ID 分隔 R2 路径；不沿用旧学习路线的匿名 `simulearn_uid`。客户端不能指定私有数据所属账户。

每次更新要求当前 revision，并保留不可变历史快照；冲突返回 409，避免覆盖另一设备的更新。恢复历史通过创建新版本完成。

公开是单独操作：编辑 `publicBody`、预览、人工核对并确认。公开接口只返回标题及公开正文等允许字段，不返回 `fields.raw`、个人状态、私有证据链接或引用对象。作者应在公开正文中人工加入可公开来源。公开后修改也需要再次确认；切回私人立即关闭该公开入口。

Markdown 导出适用于迁移与人工发布。JSON 备份包含私有字段，下载前应留意保存位置。本版本以链接/文字描述登记附件，未实现新的二进制附件上传流程；跨设备同步仅包括已成功保存的文字和引用。

## 部署与验证

继续使用原站 Cloudflare 发布流程，新增 `/api/study` 和 `/api/study/*` 的 Worker 优先路由。沿用现有 `BOOKS` 存储、`JWT_SECRET` 与 Dify 配置，不需要新建数据库或迁移旧学习路线数据。

建议使用 Node 24（与仓库 CI 一致），运行 `npm ci`、`npm run test`、`npm run build`、`npm run check:functions`，再运行 Worker dry-run 编译。真正的账户多设备访问、生产 R2 条件写入和 Dify 调用需部署后以真实账户验收，不能从公开登录页或本地测试结果推导已经通过。

原站部署命令为 `npm run deploy:site`；教程升级不重启 CAE 后端。发布时保留原站完整 `/cae/` 静态构建。

本地验收（2026-10-23）：24 项 Vitest 测试、17 项 Playwright 浏览器回归通过；完整 CAE 前端和 Astro 35 页构建通过；Functions 编译及 Worker 部署 dry-run 通过。浏览器验收使用本地 Worker/R2 和合成测试账户，验证了保存、版本历史、过期版本冲突、公开前确认、公开字段隔离和撤回。AI 页面流程采用明确的接口测试夹具；真实 Dify 调用尚未验证。生产未部署。

仓库原有根 lockfile 未包含已声明的 CAE workspace，导致 `npm ci` 失败。本次以现有 package.json 重新生成 lockfile（未新增依赖声明），`npm ci --dry-run` 已通过。测试配置只在本地启动时提供开发签名密钥和 mock AI 模式；不会修改生产变量。浏览器回归屏蔽外部字体请求，避免网络可用性影响功能测试。

## 单位案例复核记录

中文与英文失败博物馆的密度案例改为资料复核示例，去除无运行证据的频率、排查耗时和发生日期。复核日期仅表示编辑核对时间。

Ansys Mechanical APDL 2025 R2 `/UNITS` 列出 MPA 为 mm、Mg、s、°C，且明确该命令仅标记单位，不转换已有数据。MPa 与 mm 兼容；以 7850 kg/m³ 为假定值，其等价密度为 7.85×10⁻⁹ Mg/mm³。该换算是量纲推导，不是已运行仿真。

关键结论核对范围为下列章节，未声称已阅读整部文档：

- [/UNITS](https://ansyshelp.ansys.com/public/views/secured/corp/v252/en/ans_cmd/Hlp_C_UNITS.html)
- [System of Units](https://ansyshelp.ansys.com/public/views/secured/corp/v252/en/ans_cou/Hlp_G_COU1_3.html)
