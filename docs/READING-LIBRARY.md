# 收藏与最近浏览

更新日期：2026-10-24（Asia/Shanghai）。本轮仅扩展教程模块，沿用现有 Astro / Cloudflare 发布流程。

## 使用流程

搜索结果、成功加载的知识教程、已发布案例和报错卡片提供收藏按钮。按钮与搜索结果链接分开，收藏不会触发跳转。导航书签图标、资源菜单及快捷搜索均可进入 `/library/`。

最近浏览仅记录成功显示的公开知识教程、当前工程案例和用户展开的报错详情；进入报错列表不会登记所有错误。加载中或加载失败的教程、搜索查询、私人学习工作台、共享记录和附件均不自动记录。首页在有浏览记录时展示最近三条入口。

公开教程和案例现已接入[继续阅读与长文工具](./ARTICLE-READER.md)。有已存位置的最近条目提供续读入口；移除或清空浏览记录会同时清理对应阅读位置，正常清理保留字号设置。

收藏与最近浏览独立管理，不推导已阅读、学习完成或已掌握。管理页支持标题/关键词与内容类型筛选、逐条移除、暂停或恢复浏览记录、确认后清空浏览记录，以及 JSON / Markdown 导出。导出包含当前浏览器完整的两个列表，不受当前页面筛选影响。

## 持久化与限制

采用 `simulearn-reading-library-v1` 单独的 localStorage key；不读取账户或私人学习内容，不调用 AI 或保存学习进度。数据仅位于当前浏览器与当前站点域名，同浏览器标签页会刷新状态，暂不跨设备或跨浏览器同步。清理站点数据会移除列表，可提前导出备份；本轮未提供导入。

最多保留200项收藏和50条最近浏览。收藏达到上限时提示先移除；浏览按最近打开置顶、相同链接去重并淘汰最早的记录。暂停保留已有记录，恢复后仅登记后续访问。清空最近浏览不删除收藏或文章。

只保存站内公开元数据（标题、摘要、链接、类型、领域、错误代码与操作时间），链接经过站内路由白名单和长度校验。列表渲染使用文本节点。浏览器拒绝存储或空间不足时返回失败，不显示保存成功。自动浏览写入遇到任何损坏数据会保留原始值；已知v1的部分损坏数据可在用户显式列表操作时清洗保存，无法识别的版本或坏JSON需用户确认重置本功能后才移除。重置不触碰其他站点存储。

新增收藏与最近浏览的公开入口进入搜索索引后，索引共611项（532个知识点、60条报错、18个页面、1个案例）；个人列表本身不进入公开索引。
