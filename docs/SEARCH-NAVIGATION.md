# 首页搜索与导航优化

更新日期：2026-10-24（Asia/Shanghai）。沿用教程模块和现有 Cloudflare 发布流程。

## 使用入口

- 首页资源栏下提供可直接提交的站内搜索，附 CSV、接触不收敛和围岩案例示例。
- 中文导航搜索按钮、手机顶部搜索按钮、Ctrl/Cmd+K 或 `/` 打开快捷搜索。输入框、可编辑区域及其他对话框内不会拦截快捷键；支持上下选择、Enter 打开、Escape 关闭和焦点归还。
- `/search?q=CSV&domain=tools&type=kp` 可分享搜索词及独立领域/类型筛选。旧 `/search#ANSYS-004` 自动兼容；浏览器前进后退保留状态。
- 报错结果跳转后自动展开目标详情，并避开固定导航；同页更换有效错误锚点也适用。

## 内容与边界

公开索引包含532个知识点、60条实际错误卡、17个公开页面入口和1个案例，共610项。知识点来自既有知识目录，错误条目构建时从实际 ErrorLookup 数据生成，避免维护第二份错误列表；索引与当前报错卡锚点关系由测试检查。

学习记录只收录工作台入口，不读取用户记录、资料卡、附件、私有结果或审核稿。搜索无需登录、不调用AI、不保存本机搜索历史。所有结果经过站内路由白名单约束。

精确错误代码与标题优先，支持全角/大小写规范化、常见工程别名和中英多词AND；不再按任意一个常见汉字匹配大量不相关结果。领域名“热”单独可检索。查询最多120字符，结果总数按全部匹配计算，先展示20项并可继续加载。

该索引检索的是构建时公开目录、标题、摘要和关键词；不是私人笔记搜索，也不包含运行时R2内容覆盖的全文。动态覆盖或正文中的新说法不会在未更新索引前自动纳入。新增公共页面需更新索引目录；新增知识点和错误卡随构建自动纳入。现有英文搜索保留，新增快捷搜索面向中文站。

## 导航与验收

补充“跳到正文”、下拉互斥、Escape/外部点击收起菜单。当前页标记采用精确路径；知识页由静态模板提供时，根据浏览器实际URL补正领域/工具归属，不把模板路径当作当前位置。

验证覆盖公开索引完整性、实际错误锚点、别名/多词检索、计数与过滤、输入安全、分享链接、浏览器历史、输入法、快捷键编辑区保护、失败降级、键盘焦点、移动/暗色、错误深链接与现有学习流程。

本次本地验收：33项单元测试、32项浏览器测试通过；两个搜索客户端脚本的定向TypeScript检查、Astro构建及Worker部署预检通过。浏览器测试使用本地Worker，涉及学习记录的测试数据和AI模拟仅存在于本地环境。
