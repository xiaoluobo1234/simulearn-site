# CSV 实验结果到私人学习记录

范围：教程模块。此版本在 CSV 项目四种输入与真实 Python 实验之上，连接本地结果文件预览和已有私人学习记录编辑器。教学内容版本为 `csv-checker-v2`；固定输入契约仍为 `csv-checker-v1`，没有因此更换 CSV 格式或检查算法。内容仍待人工审核。

## 用户流程

1. 在 Python 实验台手动运行，导出本次结果 JSON。
2. 在学习记录选择文件，本地预览环境、状态、原始输入、代码、stdout、stderr 和文件指纹。
3. 核对后明确应用为一份新的、未保存的私人草稿；既有记录不会被作为更新目标。未保存修改需先确认处理。
4. 用户补充实际日期、问题、理解和下一项任务，自行决定复现与学习状态。匿名也可导出当前草稿；账户保存沿用已有显式保存按钮。

文件选择、预览与应用不执行文件中的代码、不向 AI 发送内容、不写入 API 或浏览器持久存储。记录保存是后续单独动作，使用现有账户权限和版本流程。

## 数据与证据边界

- 仅接收支持格式的已结束 Python 结果 JSON，最大 30 KiB；严格核对 UTF-8、字段、时间、运行声明、长度与危险结构。装配结果不进入这个导入流程。
- `csvResultOriginal` 保留完整原文，`csvResultMetadata` 保留实际文件 SHA-256、字节数、文件名、导入时间以及文件自述的运行信息。原始文件、元数据和可编辑整理稿分开；编辑整理稿不改原文。
- SHA-256 只标识所选字节。模板和输入比对只说明文本与当前公开文件相符，不证明文件作者、执行历史或输出真实。修改过的 Python 代码仍可归档，但不套用固定 CSV 案例或轴杆公式结论。
- 文件声明 `succeeded` 不等于 CSV 检查无问题。导入不变更为已运行、已复现、已掌握、已核对或已公开，个人学习日期亦不由文件时间推导。
- 字段和展开请求体预先检查上限，超限拒绝且不静默裁剪。完整 JSON 导出与私人保存保留原文；Markdown 的文件源文本采用字面文本表示。
- 账户身份与编辑上下文变化时撤销旧的异步预览、记录读取和 AI 建议；保存前核对连接账户。工作台写入携带预期账户，服务端将其与本请求已认证账户比较，不一致即拒绝，避免在核对和写入之间切换账户导致错存；此字段本身不能认证身份。旧客户端不携带该字段时保持原有兼容行为。

## 维护者验证

模型专项测试位于 `tests/csv-result-record.test.ts`；界面与竞态测试位于 `tests/e2e/csv-result-record.spec.ts`；真实浏览器 Python → 本地私人账户保存 → 重载 → 公开读取拒绝的验收位于 `tests/e2e/csv-result-record-real.spec.ts`。

测试采用本地合成账户和教学数据，不能登记为真实试学、用户运行经历或学习效果。实际通过范围以本轮日志及对应提交的 CI 为准；人工审核人、日期和结论仍为空。

2026-10-25 本地验收已通过 270 项单元测试、171 项浏览器测试、完整构建 56 页及 Functions 编译。真实链路包括 Python 非数值 CSV 输出、独立新记录保存、重载后原文与元数据相同、原账户记录未变和公开读取 404。双账户 JWT 单元验证包括匹配、错配、畸形及缺省 `expectedOwner`，错配未写存储或调用 AI。导入模型、编辑器和新增真实链路测试的专项类型检查通过；服务端依赖图仍有与 HEAD 相同的 6 项既有严格类型诊断，本轮没有新增诊断，未将此称为整仓严格类型零错误。
