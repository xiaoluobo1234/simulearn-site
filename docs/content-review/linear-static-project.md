## 3. 三套案例完整审核文稿

共同条件：小位移或小应变、线弹性、无分布载荷、自重和惯性。各包实际组装单元刚度、分区求自由位移，再用未改写的原矩阵恢复反力，未调用商用求解器。输入严格声明 mm、N、MPa 和 rad，程序不自动换算单位。

### 3.1 均匀杆：端拉位移、反力与能量

- 页面：`/cases/benchmarks/uniform-bar/`。
- 提交练习：`/learning/projects/linear-static/?case=uniform-bar#project-practice`。
- 案例内容状态：`draft`。

从两节点轴杆开始，核对单元刚度、支承反力与应变能。附可独立运行的输入、标准库脚本及 AI 环境实际参考输出；待本人复核与本机复现。

**模型与正方向**

一维轴向线弹性杆；左端 u0=0，右端沿正轴向施加 +10000 N。

**标准参数**

| 参数 | 值 | 单位 / 说明 |
| --- | --- | --- |
| 弹性模量 E | 210000 | N/mm² |
| 截面积 A | 100 | mm² |
| 杆长 L | 1000 | mm |
| 端部力 P（向右为正） | +10000 | N |

**假设**

- 小应变、线弹性、均匀截面，仅保留轴向位移。
- 左端轴向固定；无分布载荷、自重、惯性与初始应变。

**从输入到核查的步骤**

1. 核对 input.json 的单位、符号与网格。
2. 按 EA/h 生成单元矩阵，按连接关系累加到整体矩阵。
3. 分区施加 u0=0，求自由位移；用原矩阵计算 R=Ku−F。
4. 计算 U=uᵀKu/2，并独立比较 PL/(EA)、−P 与 P²L/(2EA)。

**标准参考目标量**

| 目标量 | 教学目录参考值 | 单位 | 定义与解释 |
| --- | ---: | --- | --- |
| 右端轴向位移（`tip-displacement`） | 0.47619047619047616 | mm | 向右为正；解析参考 PL/(EA)=10/21 mm。 |
| 左端轴向反力（`reaction-force`） | -10000 | N | 支承作用于杆的力为负向，R0=−P。 |
| 总应变能（`strain-energy`） | 2380.9523809523807 | N·mm | U=Pδ/2；约 2.380952381 J，不能把 N·mm 直接标成 J。 |

### 3.2 两段阶梯杆：连接、柔度与端部响应

- 页面：`/cases/benchmarks/stepped-bar/`。
- 提交练习：`/learning/projects/linear-static/?case=stepped-bar#project-practice`。
- 案例内容状态：`draft`。

两段截面与长度不同，界面共享节点，仅右端承受拉力。用相容、平衡及能量三条链核对组装；本例没有界面集中外力。

**模型与正方向**

一维串联两段杆；节点坐标 0、400、1000 mm，u0=0，F=[0,0,+10000] N。

**标准参数**

| 参数 | 值 | 单位 / 说明 |
| --- | --- | --- |
| 两段弹性模量 E | 210000 | N/mm² |
| 两段长度 L1 / L2 | 400 / 600 | mm |
| 两段面积 A1 / A2 | 100 / 50 | mm² |
| 右端力 P（向右为正） | +10000 | N |

**假设**

- 各段线弹性、段内 EA 恒定；界面位移连续。
- 界面没有额外节点力，两段轴力均为 +10000 N。
- 忽略自重、惯性、截面突变附近的三维应力集中。

**从输入到核查的步骤**

1. 分别计算两段 EA/h，界面节点贡献必须相加而非覆盖。
2. 仅施加左端轴向零位移，求解其余节点。
3. 用原矩阵恢复反力，分段比较伸长及轴力。
4. 以串联柔度 C=400/(EA1)+600/(EA2) 独立核对 δ=PC 与 U=P²C/2。

**标准参考目标量**

| 目标量 | 教学目录参考值 | 单位 | 定义与解释 |
| --- | ---: | --- | --- |
| 右端轴向位移（`tip-displacement`） | 0.7619047619047619 | mm | 向右为正；两段伸长约 0.190476190 与 0.571428571 mm。 |
| 左端轴向反力（`reaction-force`） | -10000 | N | 支承作用于杆的反力为 −P；界面是内部连接。 |
| 总应变能（`strain-energy`） | 3809.5238095238096 | N·mm | U=Pδ/2；约 3.809523810 J，等于各段能量之和。 |

### 3.3 悬臂梁：有符号挠度与弯曲能量

- 页面：`/cases/benchmarks/cantilever-beam/`。
- 提交练习：`/learning/projects/linear-static/?case=cantilever-beam#project-practice`。
- 案例内容状态：`draft`。

用两节点 Euler–Bernoulli 弯曲单元组装悬臂梁。横向向上为正，端力向下，端位移应为负；同时保留固端力矩核查。

**模型与正方向**

均匀小挠度梁，每节点 [v,θ]；固端 v0=θ0=0，右端 P=−1000 N。

**标准参数**

| 参数 | 值 | 单位 / 说明 |
| --- | --- | --- |
| 弹性模量 E | 210000 | N/mm² |
| 矩形截面惯性矩 I | 100×100³/12 ≈ 8333333.333333 | mm⁴ |
| 梁长 L | 1000 | mm |
| 右端横向力 P（向上为正） | −1000 | N |

**假设**

- 小挠度、小转角、线弹性、常 EI 的 Euler–Bernoulli 梁。
- 仅弯曲平面内的横向位移与转角，θ=dv/dx，以逆时针为正。
- 无分布载荷、自重、剪切变形、轴力或惯性。

**从输入到核查的步骤**

1. 按 [v左,θ左,v右,θ右] 构造 4×4 弯曲单元刚度并组装。
2. 分区施加固端两项运动条件，求节点位移与转角。
3. 用原矩阵恢复固端力与力矩，分别检查 N 与 N·mm 残差。
4. 独立比较 v(L)=PL³/(3EI)、R=−P、U=P²L³/(6EI)，另查固端力矩 −PL。

**标准参考目标量**

| 目标量 | 教学目录参考值 | 单位 | 定义与解释 |
| --- | ---: | --- | --- |
| 自由端竖向位移（`tip-displacement`） | -0.19047619047619047 | mm | 向上为正；向下端力产生负挠度，不能仅比较绝对值。 |
| 固端竖向反力（`reaction-force`） | 1000 | N | 支承作用于梁的力向上；另有 +1000000 N·mm 固端反力矩。 |
| 总弯曲应变能（`strain-energy`） | 95.23809523809524 | N·mm | U=P·v(L)/2 为正；约 0.095238095 J。 |

## 4. 方向、反力与能量：共同核查口径

### 4.1 先确认结果的对象和正方向

- 两种杆均以向右为正：右端外力 `+10000 N`，支承作用于杆的轴向反力为 `−10000 N`。
- 悬臂梁以向上位移、逆时针转角为正，节点自由度次序是 `[v0,θ0,v1,θ1,…]`。端部力 `−1000 N` 产生负端位移；固端竖向反力 `+1000 N`、反力矩约 `+1000000 N·mm`。
- 反力是支承对结构的作用，不是结构对支承的相反作用；数值比较不先取绝对值。
- 反力用原始 `R=Ku−F` 恢复，不能拿为施加位移边界而替换后的约束行计算。梁的平移力残差用 N，转动力矩残差用 N·mm，分别记录。

### 4.2 应变能不是最终力乘位移

本轮零位移支承、无初始应变的线弹性模型中，`U=uᵀKu/2=P·δ/2`；梁的负力乘负位移仍为正能量。一般规定位移非零时应保留约束反力项：`U=(uᵀF+u_cᵀR_c)/2`，不能无条件省略。把该终态半乘积逐项解释成实际外力功，还需相应的从零比例准静态加载条件。

`1 N·mm=0.001 J`。三案例能量约为 `2.380952381 J`、`3.809523810 J`、`0.095238095 J`。把 N·mm 数值直接标成 J 会相差千倍。

本练习只做给定矩阵/向量的后处理计算，不执行有限元组装或求解，不运行商业 CAE；梁的转角、混合力与力矩单位、热初始应变及非线性耗散均不在本题范围。原始依据沿用本稿上文实际核对的 MIT Roylance 印刷第3–6页单元关系、组装及约束方程，测试数组和实现为自设教学练习。

参考实现不是自动回退项，也不是已经完成的学员提交。运行器不上传代码或改变网站记录；--implementation 执行选择的本地 Python 文件，不提供隔离沙箱。测试通过只覆盖这些输入，不证明用户已复现有限元案例或已经掌握。
