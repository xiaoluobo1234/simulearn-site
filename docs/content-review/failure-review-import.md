# 复盘备份恢复与试学起稿

整理日期：2026-10-25（Asia/Shanghai）。本轮继续教程模块，基于 PR #12；未修改账户接口、在线 CAE 或生产发布流程。

## 使用流程

1. 在私人失败复盘页选择本页导出的 JSON，预览完整内容，再点击“作为新复盘起稿”。支持未完成、空标题的草稿，实际保存时仍需补标题并满足原账户限制。
2. 也可从首次试学页导出 JSON，在复盘页选择备份，再明确选择 Python 或装配环节。旧版试学格式 1 与含实验附件的格式 2 均沿用现有严格检查。
3. 起稿仅摘录所选观察、原预测和环境自述，列出备份及所选附件的文件索引。原预测不是已证实判据，公共固定教学输入也不能证明导入文件实际使用了相同工况。
4. 异常、原因假设、排查顺序、修改、复测和下一步仍需自行填写。试学起稿的日期为空，执行者与复现状态保持原表单默认“未运行”，需要本人按实际情况修改。已有复盘恢复则保留文件中的原始自述状态。
5. 明确应用后成为新的未保存草稿，解除当前账户记录的关联。只有再次点击“保存私人草稿”才创建新记录；不会直接覆盖原账户复盘。需要更新既有记录时，应从账户列表打开其最新版本再编辑。

## 文件与声明范围

- 本地复盘 JSON 最多 128 KiB，试学备份最多 2 MiB。损坏格式、未知版本或字段、无效 UTF-8、越界内容和不在当前目录的诊断关联会拒绝，保留当前正文；不截断证据。
- 读取、预览与取消不上传文件，不执行导入代码，不将正文写入浏览器存储。选定文件的 SHA-256 仅标识内容，不能认证经历、设备或执行者。
- 试学备份中的原始结果代码、输入、stdout 和完整矩阵不会复制到账户复盘。仍需自行保留完整试学 JSON 与结果文件。观察和环境原文可能包含私人资料，保存或分享前请核对范围。
- 复盘恢复界面的本次读取元数据只在当前页面展示，未加入旧复盘格式。试学起稿的文件索引作为明确预览的复盘正文保留，仍标记待核验。
- 表单控件可能规范化换行显示。未编辑字段在恢复、账户读取和保存响应后继续保留原始文字；只有明确编辑该字段时才采用浏览器当前文本，其他字段不随之改写。
- 修改当前正文、新建、读取账户记录、保存或取消后，旧的异步读取和预览失效。导入不修改学习进度、公开状态或内容审核结论。

## 开发验收

测试使用合成自述、回环环境的临时账户和实际浏览器装配计算，验证导出、起稿、另存新复盘、原记录保留和备份恢复。它们不能充当真实参与者反馈、作者本机复现或教学审核证据。最终测试计数及远端构建状态见本轮 PR。

新增起稿逻辑纳入首次试学与诊断内容的人工审核文件集合；相关实现变化会改变文件指纹。教学内容仍待人工复核，本轮不构成生产发布批准。
