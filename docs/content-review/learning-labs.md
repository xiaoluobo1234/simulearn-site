## 收敛示例的真实来源与定义

示例来自既有 `public/downloads/mechanics-foundations/reference-results.json` 的 `variable_area_bar.meshes`：提取 `h=element_length_mm`、`value=tip_mm`，未产生新的 Python 求解记录。源码页面从原 JSON 读取这些值及原执行信息，下载的 `public/downloads/convergence/variable-bar.csv` 与其数值对应。

原执行者为 Codex AI 执行环境中的 Python 参考计算，CPython 3.12.14，时间 `2026-10-24T02:27:18+08:00`。模型为小应变、线弹性一维轴杆：`A(x)=100(1+x/1000) mm²`、`E=210000 N/mm²`、`P=10000 N`、`L=1000 mm`，左端轴向固定；不包含自重、弯曲、惯性或三维局部应力。

解析端位移为 `PL ln(2)/(EA0)=0.3300700859809263 mm`。五档 h 分别为 `1000、500、250、125、62.5 mm`，来自 N 为 `1、2、4、8、16` 的实际组装和求解。用户本机是否运行必须另行登记，不能由载入示例推断。

- 相邻绝对变化：`abs(value_finer-value_coarser)`。
- 相邻相对变化：`abs(value_finer-value_coarser)/abs(value_finer)`；细档值为零不可计算。
- 对参考绝对误差：`abs(value-reference)`；没有参考时不计算。
- 对参考相对误差：`abs(value-reference)/abs(reference)`；参考为零时不计算。
- JSON 和比较 CSV 中的相对量为无量纲小数，页面显示为百分数。首档无相邻项，无法计算的值不是零。

本工具参考了 [DOLFINx 官方误差控制章节](https://jsdokken.com/dolfinx-tutorial/chapter4/convergence.html) 中制造解和误差范数的说明，未声称阅读全文、运行 DOLFINx 或验证其所有实现。模型、原计算与适用范围以 [本仓库既有复现说明](../../public/downloads/mechanics-foundations/README.md) 和原脚本为准。

## 隐私与状态核对

收敛页仅在用户显式分析成功后发出 `{kind:'practice-check',page:'convergence'}` 页面事件。事件不含 CSV、文件名、单位、目标量、参考值或结果。是否保存该事件由共享活动模块按用户的当前开关决定，默认关闭。

学习桌显示现有账户实际保存的记录，不重写记录。可选活动仅统计当前浏览器的有限事件，跨标签暂停或清除后由每次事件重新读取开关，损坏格式停止写入。任何页面提示的“待本人复核”都不能因为单测、代码运行、答案相符、浏览时长或统计事件而自动升级。
