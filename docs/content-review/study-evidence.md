# 试学草稿恢复与实验文件归档

整理日期：2026-10-25（Asia/Shanghai）。本轮继续教程模块，基于首次试学 PR #11，未修改账户、在线 CAE 或生产发布流程。教学内容和工程判断仍待本人审核。

## 本轮范围

- 首次试学页可选择自己导出的 JSON，先预览版本、内容和来源，再明确恢复。支持前一版格式 1，以及含实验文件的新格式 2；未来版本、损坏字段、不同教学输入和不兼容内容版本会拒绝，不猜测或补写记录。
- 草稿最多 2 MiB；实验结果每份最多 256 KiB，支持站内 Python 与装配实验的既有 JSON 格式，每类最多一份。文件在当前浏览器内读取，不上传、执行代码或写入浏览器存储。
- 文件声明的执行状态、环境、时间、结果与用户自述分别保存。输入与当前教学模型相符只代表输入对照相符；格式检查、文件 SHA-256 或恢复成功都不能证明文件真实、本人运行、工程正确或能力掌握。
- 导入预览不修改当前记录。只有明确恢复或加入文件后才改变页面内存；未知格式、超限、取消、清空以及被新选择取代的异步读取，不应覆盖当前内容。
- 原始自述时间作为文件中的声明保留，本次导入时间另记。恢复不会自动开始学习、产生运行事件或修改账户进度。新增或移除实验文件会撤销对应步骤及证据步骤的手动确认，并撤销记录结束标记，观察正文保留。
- 新 JSON 草稿采用格式 2，可带走原始结果 JSON 文本、文件名、字节数、SHA-256、导入时间与未核验标记。再次恢复时重新检查原始文本与文件指纹，重新生成展示摘要，不采信上传的摘要或成功标签。
- Markdown 导出保留正文与文件索引，不嵌入完整代码和输入。需要继续恢复完整归档时使用 JSON；需要保存独立结果文件时保留实验页的原下载文件。

## 如何试用

1. 在首次试学页写下预测，打开 Python 轴杆模板或装配实验，显式运行并导出实际结果；未运行或失败时保留实际状态。
2. 返回试学页，在实验文件区域选择结果 JSON。核对文件类型、文件所述状态、环境、教学输入对照和来源指纹，再加入当前记录。导入不同输入或未运行文件不会得到“已验证”的状态。
3. 填写自己的观察与下一步，导出格式 2 的私人 JSON。它可能包含代码、输入和输出，分享前需要本人核对范围。
4. 刷新后选择这份 JSON，确认预览，再恢复。核对原始正文、手动声明、文件内容和导入来源；恢复完成仍不等于任务完成。
5. 使用旧格式 1 文件恢复时，原先没有的实验附件保持为空，不从自述文字伪造附件或执行环境。

## 审核与验证范围

导入器只做限定格式、输入对照和文件字节检查，不重算或执行导入代码，也不认证文件来自哪个人或哪台设备。浏览器来源的运行结果、本机执行、在线 CAE、AI 参考计算与用户自述仍需分别核对。

本轮未取得真实参与者的新试学反馈。合成测试账户、测试夹具、开发环境的实际 Python/JavaScript 计算与文件导入，仅用于验证软件行为，不能写成作者实践、用户满意度、完成率或学习效果。

最终单元、浏览器、构建和远端验收结果以本轮 PR 的 CI 为准。新增实现文件同时纳入现有人工审核包的相关文件集合；源码变化后需要重新核对指纹与审核范围。下载、恢复或测试通过不会批准内容发布。
