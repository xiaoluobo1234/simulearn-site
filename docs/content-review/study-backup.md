# 学习工作台备份恢复

范围：教程模块的学习记录、资料卡与知识笔记。读取原有 JSON 导出 `simulearn-study-v1`，先本地预览，明确应用后才成为新的、未保存的私人草稿。旧账户记录保持独立。保存继续使用现有按钮、预期账户核对及版本流程，未改变共享认证、API 或 CAE 服务。

## 无损数据与身份

- 支持已保存条目及未保存、标题为空的编辑稿。主条目字段逐字符保留，包括空字符串、字段缺失、CRLF、孤立 CR、未知字段及 CSV 结果完整原文。编辑器仅在真正修改控件后采用新的输入值；未修改的浏览器文本框表示不能替代备份原文。
- 标题在本地预览与 JSON 中保留原文；显式保存时沿用现有接口去除标题首尾空白的规则，空标题须先补全。旧标题仍完整留在归档声明中，这与正文及其他原字段的逐字符保留分别记录。
- 恢复不继承旧 ID、修订或账户历史，当前关联 ID 清空。新条目为 `not-started` / `draft` / `private`。旧学习、审核及公开状态只作为文件声明归档，不构成当前状态或审核批准。
- 原字段中的学习日期作为备份自述保留；导入时间单独记录，不用它生成新的学习日期。数据格式、SHA-256 及文本相同不能证明作者、实际运行、复现或学习效果。
- `studyBackupArchive` 是保留字段：保存原文件的指纹、字节数、名称、实际导入时间、旧条目声明、未绑定引用快照及缺失引用标识。它不重复存储整份备份或主字段正文。

## 引用与循环恢复

原导出只附当前可读取的直接资料卡与笔记快照，可能没有笔记内部引用的资料。恢复保留所有提供的 source/note 快照，并列出直接或内部缺失的引用 ID；不把备份中的 ID 当作当前账户的可用记录，也不自动新建资料卡。

已有归档须通过严格 schema 和快照指纹检查。新旧快照按类型、原 ID 和完整内容指纹去重；同一 ID 的不同版本保留。再次导出与恢复时，来源元记录和引用平铺合并，不嵌套旧归档，不删旧记录。归档可展开为纯文本，也可单独下载；未绑定快照仍需人工核对和关联。

文件源内容按文本预览。Markdown 导出对归档及未修改的备份原文使用字面文本；整理稿的原文指纹只用于格式判断，不表示审核通过。JSON 导出始终保留真实字符串。

## 容量与失败

解析上限为 2 MiB。应用前另核对单字段 32,000 字符、48 字段、归档单字段容量及 UTF-8 实际请求体 120 KiB 预留上限。损坏编码、未知 schema、危险键、保留字段冲突、快照指纹不符或无法无损容纳时拒绝整次应用，保留当前编辑与原文件，不截断内容或丢弃引用来凑上限。

文件选择、预览和应用不执行代码、不写浏览器持久存储、不向 AI 或账户自动上传。显式保存才写入私人账户。编辑、切换、取消、重新选择和账户变化会使旧异步预览失效；CSV 结果导入与备份恢复不会交叉套用旧预览。

## 验证范围

模型边界与循环恢复见 `tests/study-backup.test.ts`；真实 StudyStore 条件写入往返见 `tests/study-backup-store.test.ts`；界面与时序见 `tests/e2e/study-backup.spec.ts`；真实 Python 文件及双账户私人存储往返见 `tests/e2e/study-backup-real.spec.ts`。

真实链路测试采用本地合成账户和教学数据，不是用户试学或学习成果。测试、构建与远端检查结论以本轮实际日志为准，教学内容仍待人工复核。

2026-10-25 本地验收已通过 283 项单元测试、180 项浏览器测试、完整构建 56 页及 Functions 编译。其中真实双账户测试使用实际浏览器 Python 输出，验证跨账户新草稿、原文与引用归档、再次导出恢复、原账户记录未变、旧私有引用在新账户读取 404 及公开读取拒绝。专项类型检查通过；Store 测试依赖图仍有既有 `dify.ts` 泛型类型诊断，未将本轮验收表述为全仓严格类型零错误。
